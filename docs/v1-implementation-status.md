## 1. 版本结论

当前版本是纯浏览器扩展，音频捕获、识别、标点和分句均在浏览器本地完成。

当前版本可以完成：

```text
打开网页视频
→ 点击扩展
→ 打开独立字幕弹窗
→ 捕获标签页音频
→ 浏览器内 WASM 识别
→ 流式分句
→ 生成终稿字幕
→ 点击字幕跳转视频
```

用户侧不需要：

- Python。
- Node.js。
- 本地推理服务。
- 启动脚本。
- API Key。
- 远程服务器。
- 网络请求。

Node.js 仅用于开发阶段的扩展构建和运行时资源下载。

> 当前版本使用 CT-Punc 分句链路。实时预览和终稿都由模型恢复标点，字幕切分优先使用模型标点边界；连接词词典和人工补标点不参与分句，模型没有给出可用边界时按字幕宽度兜底。

各阶段使用独立 Worker：

| 流程     | 输入                 | 输出                                | 执行位置            |
| -------- | -------------------- | ----------------------------------- | ------------------- |
| 音频转换 | 标签页 MediaStream   | 16 kHz PCM16                        | AudioWorklet        |
| 人声检测 | PCM 音频帧           | `vad.speech-start/frame/end`        | VAD Worker          |
| 语音识别 | VAD 语音帧           | `asr.caption` 原始文本              | ASR Worker          |
| 标点恢复 | `asr.caption`        | `punctuation.result`                | Punctuation Worker  |
| 字幕分句 | `punctuation.result` | `caption.preview` / `caption.final` | Segmentation Worker |
| 故障透传 | `asr.caption`        | 单条 UI 字幕                        | Offscreen           |

后处理 Worker 在采音期间后台初始化，不阻塞音频捕获。

### 2.8 稳定性保障

| 场景                         | 当前行为                                                    |
| ---------------------------- | ----------------------------------------------------------- |
| 暂停、恢复或跳转后的识别结果 | `recognitionEpoch` 隔离旧代次，Offscreen 和 Panel 双层丢弃 |
| 进入已生成区间               | 暂停识别并清除全部临时字幕                                  |
| 快速重复启动、停止或关闭     | Background 使用统一串行队列处理会话操作                     |
| 音频轨道结束或标签页关闭     | 自动停止会话并清理资源                                      |
| 多视频页面切换               | 页面和 Panel 校验 `videoId`，旧视频状态失效                 |
| 页面播放状态更新             | 使用单调 `sequence`，Panel 丢弃过期状态                     |
| 播放器调度                   | 响应播放器事件，并按字幕区间边界调度                        |
| VAD 开关判断                 | 使用 Silero 概率、噪声底和信号峰值计算自适应门限            |
| 同一语音段的临时字幕         | 只保留最新预览组                                            |
| 正式构建                     | `esbuild` 压缩构建，不生成 sourcemap                        |

## 4. 部分实现内容

以下功能已有第一版实现，但还不是最终质量：

| 功能     | 当前实现                           | 限制                                               |
| -------- | ---------------------------------- | -------------------------------------------------- |
| 分句     | CT-Punc 标点边界优先，最大宽度兜底 | 模型未给出标点时只能按宽度断开，可能在词组内部切分 |
| 标点     | 实时预览和终稿均使用 CT-Punc       | 高频预览推理会增加 CPU 占用，低配设备可能出现延迟  |
| VAD      | Silero VAD v5 概率和自适应门限     | 预热期和复杂音乐、混响、远场声音仍可能误判         |
| 实时字幕 | 流式 ASR + 预览组整体替换          | 文本修订时同一段的多条预览可能发生视觉跳动         |
| 终稿识别 | 当前流式模型重新解码完整语音段     | 没有独立高精度终稿模型                             |
| 语言支持 | 中英双语模型                       | 当前只承诺中文视频识别                             |
| 页面适配 | 顶层页面标准 `<video>`             | iframe 和复杂播放器支持不完整                      |
| 音频范围 | 整个标签页音频                     | 页面广告、提示音等也会进入识别                     |
| 弹窗     | Chrome 原生 popup 窗口             | 不支持系统级始终置顶和自定义原生标题栏             |

第一版当前按以下标准定义完成：

1. 用户只安装一个 Chrome 扩展。
2. 不需要远程服务器和本地辅助服务。
3. 可以捕获标签页音频并保持原视频声音播放。
4. 可以在浏览器内完成中文流式识别。
5. 可以显示临时字幕和终稿。
6. 可以边生成边分句，并用最新预览组替换当前临时字幕。
7. 点击终稿可以跳转视频且不重复生成字幕。
8. 字幕列表支持自动滚动和手动查看。
9. 默认不使用远程网络。
10. 模型、WASM 和第三方许可证随扩展包提供。
