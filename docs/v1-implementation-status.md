## 1. 版本结论

第一版已经完成从“浏览器扩展 + Python 本地服务”到“纯浏览器扩展”的架构替换。

当前版本可以完成：

```text
打开网页视频
→ 点击扩展
→ 打开独立字幕弹窗
→ 捕获标签页音频
→ 浏览器内 WASM 识别
→ 流式分句
→ 生成终稿字幕
→ 点击字幕跳转视频
```

用户侧不再需要：

- Python。
- Node.js。
- 本地推理服务。
- 启动脚本。
- API Key。
- 远程服务器。
- 网络请求。

Node.js 仅用于开发阶段的扩展构建和运行时资源下载。

> 当前调试版本已注释分句和 CT-Punc 后处理，每个 VAD 语音段直接输出一条 ASR 原始字幕。识别与后处理已拆成独立的 ASR Worker 和 Caption Worker，代码没有删除，取消 `caption-worker.ts` 中的对应注释即可恢复。

两条流程的边界如下：

| 流程 | 输入 | 输出 | 与其他流程的关系 |
| --- | --- | --- | --- |
| 音频识别 | 16 kHz PCM | `asr.caption` 原始预览和终稿 | 只等待 ASR 模型就绪，不等待分句或标点模型 |
| 字幕断句 | `asr.caption` | `caption.preview` / `caption.final` | 独立 Worker 和独立队列，异常时不回滚 ASR |
| 故障透传 | `asr.caption` | 单条 UI 字幕 | Caption Worker 未就绪或不可用时直接显示原始识别 |

Caption Worker 在 ASR Worker 就绪后与采音建立过程并行初始化，不阻塞音频捕获。

## 4. 部分实现内容

以下功能已有第一版实现，但还不是最终质量：

| 功能 | 当前实现 | 限制 |
| --- | --- | --- |
| 分句 | 标点、连接词、长度规则 | 可能产生不自然的断句 |
| 标点 | 终稿使用 CT-Punc；临时预览仍为规则分句 | 临时预览不带模型标点 |
| VAD | RMS 能量阈值 | 音乐、噪声和低音量语音可能误判 |
| 实时字幕 | 流式 ASR + 稳定前缀 | 较早前缀锁定后不会实时修订，只由终稿纠正 |
| 终稿识别 | 当前流式模型重新解码完整语音段 | 没有独立高精度终稿模型 |
| 语言支持 | 中英双语模型 | 当前只承诺中文视频识别 |
| 页面适配 | 顶层页面标准 `<video>` | iframe 和复杂播放器支持不完整 |
| 音频范围 | 整个标签页音频 | 页面广告、提示音等也会进入识别 |
| 弹窗 | Chrome 原生 popup 窗口 | 不支持系统级始终置顶和自定义原生标题栏 |

## 8. 第一版完成标准

第一版当前按以下标准定义完成：

1. 用户只安装一个 Chrome 扩展。
2. 不需要远程服务器和本地辅助服务。
3. 可以捕获标签页音频并保持原视频声音播放。
4. 可以在浏览器内完成中文流式识别。
5. 可以显示临时字幕和终稿。
6. 可以边生成边分句，并只更新尾句。
7. 点击终稿可以跳转视频且不重复生成字幕。
8. 字幕列表支持自动滚动和手动查看。
9. 默认不使用远程网络。
10. 模型、WASM 和第三方许可证随扩展包提供。
